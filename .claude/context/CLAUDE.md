# Context System

This folder stores durable assistant memory.

Read memory files in this order:

1. `memory/user_preferences.md`
2. `memory/user_projects.md`
3. `memory/work_status.md`
4. `memory/learnings.md`

Project-specific context belongs in `projects/`. Session summaries belong in `session-logs/`.

Keep durable facts compact, current, and attributable to Sanchit's approved corrections or completed work.
