# Output Styles

Use these style files when Sanchit asks for a specific kind of output.

- `conversation.md`: default PA conversation.
- `email.md`: email drafts.
- `quick-reply.md`: short DM/message replies.
- `meeting-summary.md`: meeting summaries.
- `blog-post.md`: long-form posts.
- `youtube-script.md`: scripts.
