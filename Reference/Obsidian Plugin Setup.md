# Obsidian Plugin Setup

Active Obsidian vault path:

`D:\0_OTT`

Install from Settings -> Community Plugins -> Browse:

| Plugin | Required | Why |
| --- | --- | --- |
| TaskNotes | Yes | Task management with views, scheduling, time tracking |
| Dataview | Yes | Query notes using frontmatter and folders |
| Calendar | Recommended | Daily navigation |
| Excalidraw | Optional | Diagrams and whiteboarding |
| Style Settings | Optional | Theme controls |

After installing, restart Obsidian once so plugin APIs and views initialize cleanly.
